# External Language Education

[Открыть сайт на GitHub Pages](https://signatureq.github.io/external-language-education/)

Многостраничный сайт для согласования с клиенткой. Текущая версия для визуального согласования: тёмный сливовый фон, светлый текст и коралловый акцент. Полное содержимое и 14 связанных страниц; новая версия ещё не утверждена клиенткой.

## Запуск

```sh
npm run dev
```

Открыть http://127.0.0.1:4173/. Зависимости npm не нужны: используется Python 3.

## Редактирование

- `build.py` — общий шаблон и содержимое 14 страниц. После редактирования: `npm run build`.
- `styles.css` — общие стили и адаптация.
- `app.js` — меню, фильтры языков, расчёт оплаты, выбор расписания и состояния формы.
- `content.json` — данные семи языковых программ.
- `assets/photos/approved/` и `assets/photos/blue/` — фотографии направлений и иллюстрации занятий. Название папки `blue` историческое; изображения используются и в тёмной версии. Источники и промпты: `ASSETS.md`.

Главная, поступление, собеседование/пробный урок, стоимость, формат, расписание, каталог и семь отдельных языковых страниц.

## Границы текущей версии

Форма полностью демонстрирует заполнение, проверку и подтверждение, но не отправляет данные и не сохраняет их. Платёжная система и доставка заявок не подключены. Точный адрес, контакты, юридические реквизиты и настоящие фотографии школы пока не предоставлены. Иллюстрации интерьера не выдаются за фотографии школы. Сайт доступен для согласования на GitHub Pages. Форма остаётся демонстрационной.

## Проверка текущей версии

Снимки главной и внутренних страниц на ширинах 1440, 726 и 390 px, результаты проверки ссылок и сценариев находятся в `.impeccable/review/dark/`. Проверены фильтры, меню, цены, расписание, валидация и подтверждение демонстрационной формы. Интерактивных тестов и викторин на сайте нет.

## Публикация

GitHub Pages публикует ветку `main` из корня репозитория. `.nojekyll` отключает обработку Jekyll. После правки шаблонов выполните `npm run build`, затем отправьте обновлённые HTML/CSS/JS и материалы в `main`. Ссылки относительные, поэтому работают и в проектном адресе Pages.
