# External Language Education

[Основной сайт](https://externlangschool.ru/) · [Предпросмотр на GitHub Pages](https://signatureq.github.io/external-language-education/)

Многостраничный сайт языковой школы: главная, поступление, пробный урок, обучение, расписание, стоимость, каталог семи языков и две страницы о персональных данных. Основное оформление — песочное с графитом; дополнительные палитры доступны через `palettes.html`.

## Сборка и запуск

```sh
python3 build.py
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:4173/`. Зависимости npm для сайта не нужны. Те же команды доступны через `npm run build` и `npm run dev`.

## Основные файлы

- `build.py` — шаблоны и содержимое 16 страниц.
- `styles.css`, `palette-colors.css`, `refinements.css` — оформление и адаптация.
- `motion.css` — переходы кнопок, карточек и навигации.
- `app.js` — меню, фильтры, расчёт оплаты, выбор времени, оглавления документов и анимации появления.
- `content.json` — семь языковых программ.
- `legal_documents.py`, `legal.css` — содержание и оформление правовых страниц.
- `legal-settings.json` — реквизиты оператора, дата редакции и срок обработки заявок.
- `site_config.py`, `seo.py` — основной домен, поисковые метаданные и генерация файлов индексации.
- `assets/photos/` — исходные фотографии сайта.

После изменения источников выполнить сборку и сохранить обновлённые HTML вместе с источниками. Версии CSS и JavaScript рассчитываются автоматически.

Анимации появления проигрываются один раз при прокрутке. Вопросы раскрываются плавно, смена периода оплаты и времени занятий сопровождается коротким переходом. Учитывается системная настройка `prefers-reduced-motion`, в том числе при её изменении на открытой странице. Без JavaScript всё содержимое остаётся видимым. Библиотеки анимации и непрерывные эффекты не используются.

Между страницами используются [нативные View Transitions](https://developer.chrome.com/docs/web-platform/view-transitions/cross-document): содержимое мягко сменяется, шапка остаётся на месте. Начальные анимации блоков согласованы со снимком новой страницы. В браузерах без межстраничного API следующая страница плавно появляется. Ссылки, якоря, новые вкладки и история работают стандартным способом; при уменьшении движения переход отключён.

## Персональные данные и форма

[Политика обработки персональных данных](https://signatureq.github.io/external-language-education/privacy.html) и [согласие на обработку](https://signatureq.github.io/external-language-education/consent.html) доступны из подвала и формы.

Владелец пока не предоставил наименование юрлица или ФИО ИП, ИНН, адрес и email для обращений. В документах это обозначено прямо. Заполнить поля `operator` в `legal-settings.json`, затем обновить дату и пересобрать страницы. В качестве начального условия предусмотрено хранение заявок не более 180 дней; перед запуском оператор должен подтвердить или изменить этот срок.

Приём заявок не подключён. Поля формы и отправка отключены; сайт не показывает ложное подтверждение, не сохраняет содержимое заявки и не передаёт его третьим лицам. Ссылки на документы доступны. До начала сбора данных нужно подключить фактический канал доставки, согласовать меры защиты и хранение, реализовать проверку отдельного согласия и фиксацию его версии, даты и действия посетителя. Заполнение реквизитов само по себе отправку не включает.

Собственные счётчики, рекламные пиксели и аналитические cookie не используются. Основной сайт размещается в Timeweb; ссылка на политику хостинг-провайдера приведена в документе. Правовые страницы описывают текущее состояние сайта и условия будущего приёма заявок; наличие страниц не заменяет организационные меры оператора.

## Проверка

Проверены основные сценарии меню, фильтров, расчётов и выбора расписания; адаптация на ширинах 320, 390, 768 и 1440 px. После изменения документов проверить их оглавления, ссылки в подвале и форме, отсутствие заранее установленного согласия и отсутствие отправки при неподключённом канале приёма.

Материалы правовых страниц сверены 18 октября 2026 года с законом № 152-ФЗ: статьи 5, 9, 14, 18, 18.1 и 21. Правовая основа и политика хостинг-провайдера связаны ссылками непосредственно из документов.

## Поисковая индексация

Сборка создаёт уникальные description, канонические HTTPS-адреса без параметров палитры, Open Graph, Twitter Card и JSON-LD (школа, сайт, страницы и хлебные крошки). `robots.txt` разрешает обход основного сайта и указывает на `https://externlangschool.ru/sitemap.xml`. В карте 14 содержательных страниц. Правовые документы имеют `noindex,follow`, а служебная страница палитр закрыта от индексации.

Favicon использует существующую монограмму `e`: корневые PNG 120, 192 и 512 px, ICO с несколькими размерами и Apple Touch Icon 180 px. Основной URL иконки — `/favicon.png`, без меняющегося параметра версии. После публикации передать `sitemap.xml` в Яндекс Вебмастер и Google Search Console и запросить переобход главной страницы. Проверочные файлы или meta-теги владельца добавляются после получения их из кабинетов поисковых систем.

## Публикация и откат

Основной сайт: `externlangschool.ru`, Timeweb, папка `public_html`. Домен и DNS остаются в Beget; на Timeweb направляются только A-записи сайта. Не менять NS и почтовые записи при обновлении сайта.

В Timeweb загружать готовые HTML, CSS, JavaScript, папку `assets`, `favicon*.png`, `favicon.ico`, `apple-touch-icon.png`, `robots.txt`, `sitemap.xml` и `.htaccess`. Исходники Python, JSON-настройки, `.git` и документацию в публичную папку не загружать. `.htaccess` выбирает `index.html` вместо стандартной страницы хостинга `index.htm`. Перед загрузкой выполнить сборку; перед заменой опубликованных файлов сохранить их копию вне `public_html`.

Для основного домена используется бесплатный Let’s Encrypt без платного сопровождения. Перенаправление HTTP → HTTPS включается в настройках сайта Timeweb после установки сертификата. `.htaccess` перенаправляет `www` на основной домен и явные запросы `/index.html` на `/`, сохраняя параметры адреса.

GitHub Pages публикует ветку `main` из корня. Файл `.nojekyll` отключает обработку Jekyll. После сборки отправить изменения в `main` и проверить успешное завершение публикации.

Контрольные версии сохранены метками:

- `before-visual-refresh-2026-10-18` — до визуальной доработки.
- `before-photo-update-2026-10-18` — перед возвращением фотографий.
- `before-legal-pages-2026-10-18` — перед добавлением правовых страниц.
- `before-layout-details-2026-10-18` — перед доработкой уровней, расписания и заголовков.
- `before-motion-2026-10-18` — перед добавлением анимаций.
- `before-page-transitions-2026-10-18` — перед добавлением переходов между страницами.

Для отмены отдельного изменения использовать `git revert` соответствующего коммита и отправить новый коммит в `main`.

### Админка Laravel + Filament

В `cms/` находится панель для редактирования существующего сайта: страницы, языки, общие блоки, фотографии, цены, расписание и поисковые метаданные. Правки проходят через черновик, закрытый предпросмотр и явную публикацию. Инструкция по запуску, установке на Timeweb и резервному копированию — в [`cms/README.md`](cms/README.md).

После начала работы через админку содержание хранится в приватной базе хостинга. Python-сборку из корня больше нельзя загружать поверх отредактированных страниц: она используется как исходная версия и для статического GitHub Pages-превью. Для восстановления готовых страниц из базы используется `php artisan site:build`.
