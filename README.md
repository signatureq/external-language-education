# External Language Education

[Открыть сайт на GitHub Pages](https://signatureq.github.io/external-language-education/)

Многостраничный сайт для согласования с клиенткой. Текущая версия для визуального согласования: нейтральный чёрный фон, белые разделы и монохромные кнопки; также доступна светлая версия. Полное содержимое и 14 связанных страниц; новая версия ещё не утверждена клиенткой.

## Запуск

```sh
npm run dev
```

Открыть http://127.0.0.1:4173/. Зависимости npm не нужны: используется Python 3.

## Редактирование

- `build.py` — общий шаблон и содержимое 14 страниц. После редактирования: `npm run build`.
- `styles.css` — общие стили и адаптация.
- `app.js` — меню, фильтры языков, расчёт оплаты, выбор расписания и состояния формы.
- `content.json` — данные семи языковых программ.
- `assets/photos/approved/` и `assets/photos/blue/` — фотографии направлений и иллюстрации занятий. Название папки `blue` историческое; изображения используются и в тёмной версии. Источники и промпты: `ASSETS.md`.

Главная, поступление, собеседование/пробный урок, стоимость, формат, расписание, каталог и семь отдельных языковых страниц.

## Границы текущей версии

Форма полностью демонстрирует заполнение, проверку и подтверждение, но не отправляет данные и не сохраняет их. Платёжная система и доставка заявок не подключены. Точный адрес, контакты, юридические реквизиты и настоящие фотографии школы пока не предоставлены. Иллюстрации интерьера не выдаются за фотографии школы. Сайт доступен для согласования на GitHub Pages. Форма остаётся демонстрационной.

## Проверка текущей версии

Снимки главной и внутренних страниц на ширинах 1440, 726 и 390 px, результаты проверки ссылок и сценариев находятся в `.impeccable/review/dark/`. Проверены фильтры, меню, цены, расписание, валидация и подтверждение демонстрационной формы. Интерактивных тестов и викторин на сайте нет.

## Публикация

GitHub Pages публикует ветку `main` из корня репозитория. `.nojekyll` отключает обработку Jekyll. После правки шаблонов выполните `npm run build`, затем отправьте обновлённые HTML/CSS/JS и материалы в `main`. Ссылки относительные, поэтому работают и в проектном адресе Pages.

## Правки клиентки — 18 октября 2026

Сохранено принятое оформление. Позиционирование — изучение языков экстерном и интенсивная практика, включая обучение для себя. Гарантий результата к дате нет. Локация — Москва; точное место уточняется. Упоминания неподтверждённой площадки и её иллюстрации убраны. Главная сокращена: формат, группы и время занятий объединены; детали доступны на внутренних страницах.

## Светлые разделы и полнота содержания

Главная получила светлые блоки о школе, стоимости и поступлении; языковые программы — светлый раздел с этапами практики и схемой работы в парах. В каталоге семь программ и отдельная карточка помощи с выбором; фильтры заполняют ряды без пустого места. Стоимость: «Прозрачная цена. Гибкий ритм оплаты». Уточнены условия из исходных текстов клиентки: группы и уровни, личный подход преподавателя, перерывы, пробный урок, предложение и договор. Проверены ширины 320, 390, 960, 1280 и 1440 px и рабочие сценарии фильтров и расчёта оплаты.

## Сравнение палитр

[Две цветовые гаммы рядом](https://signatureq.github.io/external-language-education/palettes.html): чёрно-белая и светлая. Основная версия теперь нейтральная чёрно-белая, без фиолетового подтона и бордовых кнопок. Светлая доступна через `?palette=light`; параметр переносится в ссылки между страницами и сочетается с выбором расписания. Выбор не сохраняется в браузере. `palette-light.css` задаёт альтернативные роли цвета, `palettes.html/css/js` — отдельную страницу сравнения для согласования. Обе палитры пока варианты для выбора клиентом.
